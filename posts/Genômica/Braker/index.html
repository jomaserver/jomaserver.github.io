Contextualização

Braker é uma ferramenta de predição gênicâ, que utiliza dados de transcriptoma da referência próxima, no nosso caso a especie hexaploide (A. gerardii)

Braker3 é uma ferramenta estatística que utiliza da modelagem HMM (Modelo oculto de mmarkov) para identificação de regiões codantes.

Braker4

Recentemente, a equipe desenvolvedora do software, lançou uma versão otimizada do braker, feito com snakemade.

Porém por conflitos no ambiente conda, tive que roda a versão anterior “Braker3”

Preparação e Execução

Primeiramente, precisamos separar o arquivo fasta com as regiões de elementos transponiveis. (Softmaskedd)

Pipeline no Terminal

Rodando no servidor, os comandos para ativar o ambiente e disparar o Braker3 foram:


c3 #ativando o ambiente
conda activate Braker3 


python3 /lbi/acgt/bioinfo/GENE_FINDING/Tiberius/v2.0.6/Tiberius/tiberius.py \
  --singularity \
  --genome andropogon.primary.repeatmasked.fa \
  --out tiberius.andropogon.primary.gff \
  --model_cfg monocotyledonae \
  --batch_size 4

Resultados

Os resultados ajudaram a alimentar o software EVM (Evidence modeler) que utilizará os arquivos .gff e .gff3 para embasar a modelagem.
