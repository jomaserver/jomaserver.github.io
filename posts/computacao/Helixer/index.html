Contextualização

Outro software de predição ab initio de última geração que decidimos incluir na pipeline do capim-andropogon foi o Helixer.

Essa ferramenta é extremamente pesada computacionalmente, mas altamente precisa por utilizar modelos complexos de redes neurais.

Para dar conta do processamento, a estratégia foi rodar o Helixer otimizado para GPU.

Preparação e Execução

Acessei a máquina pardal do laboratório via SSH, que possui o hardware gráfico necessário.

Para evitar conflitos de dependências, instanciei um container Docker mapeando o diretório do nosso projeto para dentro do container (/my_data).

O primeiro passo interno foi rodar o script de fetch para baixar os modelos treinados nativos.

Em seguida, executei o software definindo a linhagem evolutiva como land_plant (plantas terrestres).

Pipeline no Terminal

Os comandos executados na máquina pardal foram:

ssh pardal

# Iniciando o container com suporte a GPU
sudo docker run --gpus all -it --rm \
  -v /st100/acgt/projetos/genfor/andropogon/jm/analysis/genemodels:/my_data \
  gglyptodon/helixer-docker:latest

Dentro do container:

# Baixando modelos 
fetch_helixer_models.py

# Rodando a predicao genica
Helixer.py \
  --lineage land_plant \
  --fasta-path /my_data/tiberius/andropogon.primary.repeatmasked.fa \
  --gff-output-path /my_data/helixer/helixer.andropogon.gff

Resultados

O uso das GPUs acelerou drasticamente o tempo de inferência do modelo sobre as sequências mascaradas.

O Helixer calculou as coordenadas dos genes preditos e nos devolveu o arquivo final helixer.andropogon.gff.

Com isso, já temos duas linhas independentes de evidências ab initio geradas.
